# MoonCam 验收入口

## 先看与先运行

- [在线工作台](https://huahai29.github.io/mooncam/web/)：选“小基圆 · 压力角不满足”，计算、搜索，再应用 36 mm 候选；最后下载 ZIP 结果包。
- [完整操作案例](完整操作案例.md)：输入文件、问题定位、调整前后对照与采样比较。
- [本地运行](本地运行.md)：克隆后无需安装 npm 开发依赖即可构建和运行。需要 moonc ≥0.10.16、Node.js 22+，验收固定工具链为 0.10.16+b1a0e846e。

```sh
git clone https://github.com/huahai29/mooncam.git
cd mooncam
npm run build
node bin/mooncam.mjs examples/workshop.json --out artifacts/first-run
npm run serve
```

保持服务终端运行，访问 http://127.0.0.1:4173/ 。下载 ZIP 并解压后，将其中 input.json 传给 CLI：

```sh
node bin/mooncam.mjs PATH/TO/input.json --out artifacts/replayed
```

输出目录必须不存在，重复演示须换新目录；拒绝已有目录的退出码为 1，不是计算失败或旧文件被覆盖。结果包里的 request.json 用于重复原始搜索，input.json 用于复算最终尺寸。
