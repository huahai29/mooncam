# MoonCam 0.4.1

要求 moonc 不低于 0.10.16，仓库与 CI 固定使用 0.10.16+b1a0e846e。JSON schema 保持 2。

```sh
moon add huahai29/mooncam@0.4.1
```

## 本版变化

- DXF 显式声明 MOONCAM 图层和 CONTINUOUS 线型，消除 FreeCAD 实际导入时的缺图层警告；坐标、毫米单位和闭合折线不变。
- 独立数值对照扩大到 205 组参数、149,983 个采样点，另有 40 位十进制参考和固定种子的随机性质测试。
- CI 在 Windows 与 Linux 生成一致性清单，严格要求两个平台齐全、CLI 成功及输出完整；相同失败不算通过。恢复性能门禁，新增 9 组比较器回归测试。
- 提供 FreeCAD 三组原生导入记录、几何对照与复算脚本。完整 GUI 截图仍未补齐，不宣称商业 CAD 全面兼容。

## 安装范围与兼容

Mooncakes 包包含纯 MoonBit 核心库、核心测试、示例和文档。网页、CLI、开发验证工具从 GitHub 仓库运行。新增测试不引入运行依赖。核心计算不需要 Python 或 FreeCAD。

DXF 图层表属于格式补全，原有 JSON 请求、状态、退出码及单位不变。计算源码指纹随版本更新；复算时请保留输入、版本、指纹和工具链信息。

仍是平面盘形凸轮与直动滚子模型的采样分析，不提供连续安全证明、全局滚轮干涉或制造认证。

## 发布验收

发布候选完成远程双平台 CI 后再上传，并核对实际归档、从注册表安装精确版本，在 JS 与 Wasm-GC 执行独立消费验证。实际结果在完成后追加，不以预检代替成功发布。
