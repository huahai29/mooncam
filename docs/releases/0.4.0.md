# MoonCam 0.4.0

本版在 0.3.0 基础上加入引擎生成信息和性能回归护栏，升级到 MoonBit 0.10.16+b1a0e846e，并提供在线工作台及更简短的中文使用说明。

## 安装

```sh
moon add huahai29/mooncam@0.4.0
```

最低编译器版本为 moonc 0.10.16；仓库与 CI 使用 .moonbit-version 固定精确版本。核心库不需要 Node.js、Python、CAD 或远程计算服务。CLI 与网页宿主仍从 GitHub 仓库构建运行。

## 变化

- JSON 响应、报告与 CLI 保存文件包含 generator：名称、包版本及生产计算源码的 SHA-256 指纹；网页展示实际加载引擎的身份。
- 增加高分辨率拓扑候选访问量与 128 段标量扫描验收，CI 检查摘要体积和宽松耗时上限。
- 提供 GitHub Pages 在线工作台；检查通过后自动部署。
- 完善 5 mm → 36 mm 的尺寸调整案例与三档采样复核，精简 README，将本地安装与排错单独成文。
- 构建检查最低编译器版本，CI 额外验证精确版本。公共接口快照按新工具链生成，整数类型显示为 Int32。

## 兼容与边界

JSON schema 保持 2，generator 为新增元数据，原有判定状态、单位和退出码不变。计算源码指纹不包含编译器与网页宿主，不等于 Git 提交；复算仍需保留输入、后端和工具链版本。

仍限于平面盘形凸轮、直动滚子、恒定正转速下的运动学和几何初选。采样通过不等于连续证明、全局滚轮无干涉或制造认证。

## 发布验收

发布前须通过四后端各 54 组核心测试、23 组接口与 CLI 测试、13 组浏览器测试、独立数值对照和 DXF 读取验证。上传后还需从 Mooncakes 安装精确版本，在独立工程执行 JS 和 Wasm-GC 验证；实际发布结果将在完成后追加。
