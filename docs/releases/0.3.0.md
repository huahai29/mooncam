# MoonCam 0.3.0

本版将 0.2 开发阶段之后的判定、解释和接入能力整理为可复用的 MoonBit 模块。包版本为 0.3.0，JSON schema 保持 2。

## 主要变化

- 段、采样点、轮廓边共用位置查询；极值直接记录点下标，网页定位与报告一致。
- 局部约束包含阈值、余量、最差位置与原因；可选同一尺寸下的多档采样比较。
- 拓扑保留有上限的交叉/不确定边对证据，计数不因证据截断而截断；G01～G19 固定验收覆盖状态和证据。
- 保守处理相切、共线与近退化，未完成和不确定不接受；报告编码显式保留定位失败原因。
- 分段 JSON 可独立校验，不采样、不清空导出缓存。网页表格支持逐段规律与导入/保存。
- 主线程兼容模式禁用采样比较，保留单档分析及导出；提供完整中文操作教程。

## 安装与分发范围

```sh
moon add huahai29/mooncam@0.3.0
```

消费方导入 `"huahai29/mooncam" @cam`。发布包保留核心源码、核心测试、纯库示例、许可证与文档；Node CLI、浏览器宿主、构建脚本及宿主集成测试从 GitHub 检出使用。运行核心分析不需要 Node.js、Python 或 CAD。

## 从 0.2 开发阶段迁移

JSON 新字段为增量信息：diagnostics、segments、crossing_evidence，以及显式启用时的 sampling_comparison。综合状态和退出码继续使用同一契约；未知状态必须保守处理，不得把不确定当作零交叉。

MoonBit 公共结构新增位置、极值下标或证据字段。通过 analyze、measure、crossing_report 等工厂函数获取结果的调用方可继续调用；手工构造 Metrics、Analysis、CrossingReport 的调用方需按公共接口快照补齐字段。CamPoint 保持原有结构。此变更不宣称对手工结构构造源代码完全兼容。

profile_crossings 继续保留，只有确定检查才返回计数；分类与证据使用 crossing_report。新增 validate_segments_json 用于轻量分段输入校验。

## 验证与边界

核心测试 52 组，覆盖 JS、Wasm、Wasm-GC、Native；另有 21 组接口/CLI 测试和 12 组浏览器用例。独立数值和 DXF 读取的观测见[验证记录](../验证记录.md)，状态与证据见[判定验收](../判定验收.md)。发布后需按[发布流程](../发布流程.md)从注册表安装精确版本并运行独立消费工程。

本版仍限于平面盘形凸轮、直动滚子、恒定正转速下的运动学和几何初选。不提供连续极值证明、全局滚轮干涉、强度载荷或制造认证；多档数值稳定不等于连续安全证明。
