# 本轮优化说明（2026-10-22）

本页记录截至 `3fdb6ae` 的历史优化；当前接口与验证数量以[接口契约](接口契约.md)、[验证记录](验证记录.md)为准。

本轮保留 `perf/search-single-fine-scan` 的细网格单次扫描与 128 段高分辨率基准改动，在其基础上修复几何判定和宿主使用问题。核心新增能力均在 MoonBit 中实现。

## 已完成

| 问题 | 处理与验证 |
| --- | --- |
| 小尺度、远离原点时漏判交叉 | 局部归一化方向符号及浮点误差界；覆盖 1e-100～1e100 尺度和相对尺度 1e6 的平移 |
| 相切、共线重叠和近退化被解释成零交叉 | 新增 `Indeterminate` 与 JSON `indeterminate`，保留确定交叉与不确定对计数；综合可行性为 false |
| x 单轴、固定桶数的性能退化 | 按主跨度轴选择 x/y，随边数增加桶数；24,000 边横窄/纵窄轮廓有访问次数回归护栏 |
| 恶意重叠时计算量失控 | 400 万桶内对访问预算，超过后明确报告检查失败；不会返回零交叉 |
| 最小因子以无穷初始化 | 改为首个有效采样值初始化 |
| 输出重复计算 | MoonBit Session 保存上次结果，Worker 内按需导出；CSV/DXF 下载不再重新分析或搜索 |
| 错误定位不足 | 输入类型、缺失字段、范围、未知字段和输出选择增加结构化 `field`；无法定位的业务错误保留 null |
| schema 字面量散落 | MoonBit 内统一常量 |
| CLI 使用不便 | 增加有字节上限的 stdin、顺序批量、独立导出目录、版本查询和四种数值覆盖参数 |
| 网页过期结果 | 请求编号、Worker 实例编号、编辑计数，拒绝旧响应并提示计算期间修改过的参数 |
| SVG 字符串直接插入 DOM | 显示由数值点构造 DOM；下载 SVG 仍由 MoonBit 生成 |
| Worker 不可用 | 主线程运行同一 MoonBit 引擎的兼容模式，明确说明无法强制超时中断 |
| 导出点数组边界 | 提供 `checked_export`，拒绝不足点数、非有限值、过大数值或未闭合输入；原始格式函数保留低层接口 |
| 验证不充分 | 新增固定种子生成案例、接受状态不变量、尺度平移、退化、预算、会话失效、CLI 和浏览器时序回归 |
| 工具链漂移、性能记录缺失 | CI 固定 `0.10.15+943464bfa`，生成并检查接口快照；保存 summary/full 与 128 段高分辨率基准 |
| 文档集中且职责不清 | 简化 README，补独立架构说明，解释三层分辨率上限与兼容字段 |

## 验证结果

- 32 项 MoonBit 测试在 JS、Wasm、Wasm-GC、Native 四个后端通过。
- 13 项接口、CLI、导出集成测试通过。
- 5 项浏览器测试覆盖桌面、移动、参数修改、晚到响应及 Worker 降级。
- 独立数值验证覆盖 18 组参数、432 个接触点。
- ezdxf 1.4.5 成功读取 3 组导出，含 18 个科学计数法坐标。
- 性能保留全量输出和摘要两种口径；摘要耗时包括 JSON 解析、分析、拓扑与摘要序列化，不称为纯计算耗时。CI 保存观测值，不以不稳定的绝对时间阈值判定通过。

## 有意保留及仍需工作

- 三层分辨率上限分别控制库调用、宿主响应和搜索复核成本，已在 API 与架构文档明确。顶层 `sample_count` 暂留兼容，建议新调用读取 `sampling.sample_count`。
- 搜索仍是有限网格的首个通过点，没有曲率单调性证明，不能安全替换为二分搜索。细网格单次扫描可能为最终拒绝的候选生成坐标，保持现有明确取舍。
- 不确定状态用于阻止误报通过，尚未采用精确算术分别证明相切、重叠或近退化类型；也不处理连续轮廓全局干涉。
- `*.generated.mbti` 是公共接口快照，应提交并检查，不作为构建垃圾删除。Native 测试和属性不变量原本已有，本轮扩展其覆盖，不将其描述为从零补齐。
- DXF 科学计数法已通过独立读取器；AutoCAD/Fusion 仍需实际应用验收，不将未验证的兼容风险当作已确认缺陷。
- 尚未发布 Mooncakes；当前支持克隆与本地依赖。发布需要独立的包发布身份与版本管理流程。
