## 独立数值方法

生产代码使用展开多项式和解析导数；验证程序使用 Bernstein 基函数表达位移，再对滚轮中心轨迹做中心差分，独立计算接触法线、实际轮廓、压力角与曲率。验证覆盖三种运动规律、三个偏置和两个基圆尺寸。差分点避开段接缝，接缝由独立的单侧连续性测试覆盖。

本次最大接触点误差约 5.98e-8 mm，最大曲率差约 2.63e-9 /mm。它们是这些算例的差分误差，不是所有输入的误差上界，也不是加工精度承诺。

DXF 测试用独立分组读取方式检查毫米声明、闭合标志、顶点数和坐标；CSV 测试检查行数、角度导数列与数值。新增 ezdxf 1.4.5 独立读取测试，3 组文件、18 个科学计数法坐标值均被接受，毫米声明、闭合标志和坐标核对通过。此结果不代表所有商业 CAD 软件均兼容，也未进行实体加工验证。

## 可复现命令

先安装 MoonBit、Node.js 22+。独立数值验证只需 Python 标准库，DXF 与浏览器验证需要开发依赖：

```sh
moon fmt --check
moon check --deny-warn --target all
moon info
moon test --target wasm
moon test --target wasm-gc
moon test --target js
moon test --target native
moon run examples/library --target wasm-gc
npm run build
npm run test:integration
npm run docs:check
python tests/oracle.py
python -m pip install -r requirements-test.txt
python tests/dxf_interop.py
npm ci
npx playwright install chromium
npm run test:browser
npm run benchmark
```

程序将摘要写入 artifacts/oracle-summary.json。浏览器测试将截图写入 test-results/。文档截图为同一测试流程产生。
