# 发布与安装验证

模块为 huahai29/mooncam。GitHub 源码与 Mooncakes 包使用同一版本号；包版本独立于 JSON schema。

## 发布前

1. 同步 moon.mod、package.json、package-lock.json、CHANGELOG 和版本说明。
2. 运行格式、严格检查、四后端核心测试、宿主集成测试、浏览器测试与文档同步检查，查看对应 GitHub CI。
3. 执行 moon package --list，审阅 _build/publish/ 中的实际归档。禁止混入凭据、用户文件、依赖缓存与生成宿主引擎。
4. 用 moon whoami 确认命名空间所有者；moon login 的授权在本机完成，凭据不进入仓库或日志。
5. 执行 moon publish --dry-run 预览，再执行 moon publish。预览或 GitHub 推送不算发布成功。

.moonignore 只影响 Mooncakes 归档：保留根库、核心测试、examples/library 和文档，排除宿主及其开发工具；GitHub 保留完整工程。

## 注册表与独立消费验证

```sh
moon view huahai29/mooncam@0.4.1 --json
```

在仓库之外创建新的 MoonBit 工程，使用注册表依赖，不能用本地路径替代：

```sh
moon add huahai29/mooncam@0.4.1
```

消费方 moon.pkg 导入 huahai29/mooncam 和 moonbitlang/core/math，构造 40 mm 基圆、4 mm 滚轮、20 mm 升程的示例程序，执行 analyze，核对采样接受、零交叉、最大压力角及实际点数。分别运行 JS 与 Wasm-GC 后端。确认依赖来自 .mooncakes/ 中的注册表包，并核对版本为 0.4.1。

只有上传和精确版本安装、执行均成功，才记录发布完成、更新后续清单并创建匹配 Git 标签。归档原文件、注册表版本和消费工程日志作为本地发布证据保存；不记录凭据。
