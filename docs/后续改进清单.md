# 后续改进清单

以下十项为尚未实现的能力。当前可运行范围以 README 和算法说明为准。

| 顺序 | 改进项 | 验收依据 |
| --- | --- | --- |
| 1 | 连续极值求解 | 在段内定位压力角、曲率极值，与高精度参考解对照 |
| 2 | 全局滚轮干涉检查 | 检测滚轮与远处轮廓的穿透，提供局部通过但全局失败的案例 |
| 3 | 相切与共线重叠识别 | 扩展严格折线交叉检查，覆盖退化情况和尺度容差 |
| 4 | 带误差界的轮廓离散 | 按弦高或几何误差自适应细分，导出离散误差记录 |
| 5 | 约束裕量与采样收敛 | 展示多级网格变化、边界裕量，不把数值稳定当作证明 |
| 6 | 更多运动规律 | 增加改进正弦等规律，验证导数和连接性质 |
| 7 | 摆动滚子从动件 | 独立几何模型、压力角定义与验证算例 |
| 8 | 平底从动件 | 实现对应包络、接触点范围与局部可实现条件 |
| 9 | 变转速与接触载荷 | 完整链式求导；载荷模块明确质量、弹簧等假设 |
| 10 | 公差敏感度与 CAD 互操作 | 扰动尺寸给出敏感度，使用独立 CAD 读取器验证导出 |

用户反馈、明确缺陷和失败用例优先于列表。各项完成后应更新适用范围与验证记录。
