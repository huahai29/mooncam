# MoonCam

MoonBit library for radial disc cams with translating roller followers.

The library synthesizes cam geometry from prescribed motion. Lengths use one
consistent user-selected unit; angles are radians and time is seconds.
The implementation covers constant angular speed, external roller contact and
closed one-revolution programs. Force, wear and elastic dynamics are outside
this kinematic model.

```sh
moon check
moon test
```
